# D13 语义与评分契约 v7

版本 recognition-semantic-scoring-7.0.0 / recognition-reference-7.0.0。作者 Codex，单作者、模型辅助、provisional；不是独立人工真值。依据 PRD 1.1 第 5 节和 PROGRESS_POLICY。旧 v6、6.0.1-diagnostic、D11 的拒绝决定均保留。

## 产品裁决

| 情形 | 可接受表示 | 不接受 |
|---|---|---|
| 当前明确行动 | 最小动作＋明确对象；条件 true/not_applicable 才 actionable | 把材料、格式、联系方式单独变成行动 |
| 明确不适用/false | 无任务且保留信息；或保留不可执行事实；S04 两种完整参照 | 默认勾选、改成条件成立 |
| unknown 条件 | 保留待核对义务及条件/事实依据 | 当 false 丢弃、当 true 直接执行 |
| 取消/替代 | 每个旧/新动作对象各有真实实体；旧端点不可执行；关系引用实体 ID | 用 scope ID 充当实体、孤立新端点、跨对象串线 |
| 模糊时间 | rawText、null、vague、needsConfirmation | 捏造日期、把公布时间当办理截止 |
| 同一时间的两个线索 | S07 可两个未知 raw 节点，或一个模糊节点＋尚未公布的信息 | 强制两个确定截止或遗漏不确定性 |
| 无任务事件 | 独立 Event/TimePoint 和来源证据，可确认知晓 | 造任务、空项目或默认提醒 |

proposition 必须支持动作与对象，允许该义务的相关属性说明；condition 支持条件前件；fact 支持 true/false/unknown 的判定事实。每份参照列 requiredAnyOf、allowed、contradictory。必要组内任一合法证据可满足，允许集内补充证据不罚；重复、无关或矛盾证据失败。不是任意超集都合法，也不是必须与一个模板的 ID 集合完全相同。

匹配先识别动作对象是否存在，再独立检查字段。错时间的任务仍可能 TP，但整项不正确；漏依赖、材料数量/required/格式/命名/渠道、父子归属、时间双向归属、完成标准、修订方向与证据都检查。匹配一对一；空匹配稳定产生 FP/FN；重复不能抵消遗漏。超过搜索界限报 MEASUREMENT_ERROR，不给满分。

允许明确列出的别名、ID 重命名、实体顺序变化。合法拆合须先在 representations 中声明相同义务覆盖、材料/时间/依赖映射；不允许运行后为了某个回答追加表示。本批不同对象/不同动作均独立，不能把多端点取消合成一个端点。S04 的省略/保留事实、S07 的时间线索拆合已有实际往返正反例。尚未列明的新拆合提出参照争议，不能自动视为禁止任务。

## 分数含义与限制

- `complete` 表示本版本所列任务义务及独立事实全部满足；不是任意自然语言答案的通用语义判官。语义别名覆盖有限，未收录的新表达要记录争议，经新版本订正，不改本批分数。
- 任务存在 TP/FP/FN、完全正确任务、关键字段错误、Severe、Forbidden 分列。Forbidden 仅来自预标注的明确禁止/失效行动；普通未匹配项不自动叫 Forbidden。
- 字段保留原文支持，不评置信度校准或 UI 的措辞美观、优先级和耗时估计。标题/自由描述的完整语义仍需人工复核；因此自动 complete 作为开发合同正确率，真人首次整份正确率仍须完整人工裁决。不能宣传为产品整体准确率。
- 独立实体证据仍按预定义支持集合严格检查；未扩大为通用释义相似度算法。文本重写过大时宁可暴露误差/争议，不用相似分数掩盖错误。
- 引用失败、Schema 失败、参照不完整、测量错误都有独立状态；不把缺失当零错误。12 份本批参照完整，部分 0，未决 0；“完整”仅限公开的 provisional 合同，并不等于独立标签或穷尽所有正确表达。
- 禁止错误行动、关键 FN、无据新增、错误时间/关系不靠其他高分抵消。缺证据可限制质量结论，不关闭已获授权且安全的工程工作。
