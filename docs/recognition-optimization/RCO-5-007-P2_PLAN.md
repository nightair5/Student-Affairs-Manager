## 唯一变量：P2 四层数据职责

1. **条件命题层**：抽取完整条件命题和后续事实命题，先比较“同一命题是否被肯定/否定”，不按孤立的“无、未”字判断。
2. **动作保真层**：已验证的原文 action surface 永远保留；`actionType` 与 `effect` 只负责归类和风险，不得改写动作文字。
3. **主体证据层**：actor 只来自命令词之前的显式主语片段；“把/将”之后的对象、动作之后的宾语和说明文字不得作为主体证据。
4. **修订状态层**：原命令的时态/极性，与当前有效性/取消状态分别计算；旧要求作废表达为历史、取消、被替代，新要求保持当前有效。
