# 下一步：实际入口与无日期下游接入范围（尚未授权）

## 目的与顺序

本轮隔离V2已经通过，下一步应让实际用户链路使用它，而不是继续反复建立新数据、调模型或重复测试同一处规则。

但原PLAN把App、下游页面与repository列为只读，不能在当前授权下直接改。先用一个有限只读审计锁定真实入口、具体文件、开关和验证方式，再申请实施；不得把此审计扩成全产品重构。
