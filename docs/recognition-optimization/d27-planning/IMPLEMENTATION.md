# D27 实现与边界

## 用户场景及实际路径

普通 `App → DashboardPage → PersonalPlanPanel` 在来源正式确认及独立读回后直接读取 canonical workspace，自动生成 `personal-plan-d27-1`。不是 ParsedSuggestion 的60分钟兼容估计，也不从UI投影重建材料/事件。`CalendarPage` 接收同一份已接受 canonical 个人安排，普通模式停止另算旧08—22单任务空档；实验历史入口保留旧行为。月历格仍表示源截止/活动；个人开工时段在日历下方单列，尚未把所有开工段混入日期格。

`personalPlanD27.ts` 提供最多14天/200任务、一任务一连续段的共同容量分配；时长5—480分钟。默认09—18、7天、未知耗时暂估30分钟明示为假设且可关闭，不是已经知道用户有空。原文/已存估计、用户估计、产品暂估有不同出处。只使用确切且完整的活动起止区间与主动录入的课程。模糊或缺边界活动、旧无可靠时长的个人计划原样保留并警示无法保证避让。

排序遵守截止、个人优先级、稳定ID；前置未完成可以先排后续时段，但保留“须实际完成前置才可开始”，不把安排等同已完成。false不适用、unknown资格、取消/历史/修订或表示缺口均不假作可执行。S06资格和依赖仍分别判定；S09独立事件作为忙碌或待定来源保留；S05时间关系仍由正式Schema和共同装配校验，本轮不重写旧scorer。

## 窄领域命令与数据安全

`applyPersonalPlan/undoPersonalPlan` 复用 `CanonicalWorkspaceRepository.transaction`。不是声称旧DomainCommitPlan已经支持重排，而是增加一个明确版本的个人安排命令，来源接受仍沿既有DomainCommitPlanV2。Schema仍v8；canonical `planned_start` 是唯一开始值，`legacyData.personalPlanD27` 仅保留经验证的时长/估计来源/锁定/operationId/前置。结束由该开始值与时长推导，不伪造event_end，不新增第二套Task。

事务内重新读当前存储，比较任务、时间/活动关联、源当前版本、课程、时区等真实读集；无关description不加入安排读集。基线是有大小上限的确切JSON，不依赖调用者旧workspace或弱hash。重算提议阻止篡改候选时段；实际事务时钟阻止把陈旧预览的新开工保存到过去。先查同operationId及相同payload的幂等回执，再查当前时钟，读回恢复不被“已过去”误拒。锁定先占用、明确解锁后才能挪动；冲突提示、不覆盖。

一笔事务写所有所选安排、历史和待读回回执。单次待验证回执限制后续写；独立Repository核对exact point snapshot+history，完成后确认回执并保留一次撤回。撤回只恢复本命令改变的个人时间点，不回滚整个workspace；相关事实已变化拒绝撤回。回执previousPoints仅能是本版合法个人起点，不能塞源截止回滚。`workspaceValidator` 对元数据和回执有窄校验和体积边界，异常保留原数据并拒绝加载；无schema迁移或无限制放大大小限制。

UI保留字段检查点及初始计量基线，错误时保留输入。已知正式提交成功、读回失败时刷新读取持久回执，明确显示已提交待验证，仅提供独立读回。两个标签无关备注可继续；关联稍后/时间/来源变化显示编辑前、最新事实与个人输入，再明确重读。普通workspace的课程/状态保存后更新canonical只读视图，不替换仍未保存的React输入。

## 计量

`personal-plan-measurement-d27-1` 是新计划操作计量，不修改历史measurement3.2、low-edit-v2或D26事实计量。变化按计划配置语义字段计，叶路径/editId保留；连续输入合并同字段ID、最终回原值计0、手动重试不再次计同一次变化。只有对应commit+readback才能称有证据的保存；缺原始编辑计数用null/MISSING，恢复不能猜0。

阅读、编辑、5秒无输入后的空闲、隐藏、系统等待分开；保存失败的已发生成本保留。刷新缺口不计阅读/编辑，也不补墙钟0。报告逐次分母、未闭合/读回缺失、可观察墙钟中位数。动作结束后查看报告不重开区间。检查点手动重试不覆盖初始基线，这是本轮实际计量复核后修复的错误。工程自动化时长不计真人四指标、不证明省时。

## 一次有限高风险复核及剩余范围

单作者工程复核检查并落实：源版本CAS、旧预览开工过期、锁定与依赖冲突、proposal篡改、撤回previousPoints污染、已提交恢复、活动/课程读集刷新、计量结束边界和重试基线。均有独立读回或最小反例；这不是独立人工质量审查，也不要求循环再审计。

第一版为确定性启发式，不保证全局最优；超过窗口/任务边界明确拒绝。未记录行程不能避让，模糊活动不能保证避让；旧不完整个人计划只保留及提示。已存方案与待接受预览同时可见，还有折叠减负空间。普通原生Schema的条件/生命周期/修订表示gap继续诚实保留sidecar，相关项阻断，不宣称所有关系完全可编辑。循环匿名坏回答的旧兼容摘要仍可见“约undefined分钟”，属于未形成事实的旧错误展示，不是可成功保存场景；本轮保存路径已明确拒绝循环且无半份事实。

没有新candidateVersion/promptVersion、模型输出或默认替换。安排工程不能抵消首次漏事实，更不能把用户补录归作首次正确。
