# D5 四项主指标测量契约

版本：`candidate13-product-metrics-1.0.0`。本契约先于D5新数据和任何新回答冻结。

1. 首次整份建议正确率：用户编辑前的首次结果与完整参照对比。任意关键任务、时间、材料、条件或关系错误，整份即不正确。后续修好不回写首次得分。
2. 正确处置率：独立语义判定为正确，且正确确认的结果已成功写入并独立读回，或对无任务来源做出正确归档。单纯点击、写入成功或全部拒绝均不足以成功。
3. 低修改正确处置率：在正确处置中，没有任务增删/拆合、动作、对象、时间、条件、材料、完成标准、修订或依赖等实质纠正。纯文案美化和个人偏好分开记录。
4. 主动修改时间：只累加已开始且未暂停的编辑段。系统等待、页面隐藏和中断分开计算。未完成的计时为`null`，不记为0。报告样本数、中位数和P95。

全部已开始的合法试次进入分母；失败、放弃、超时和语义未判定不得删除。工程回放只能验证计算和持久化，不能产生真人修改时间或转化率证据。

最小事件仅保存匿名trial/source版本、方案版本、时间戳、首次结果hash、编辑类别、终态、读回结果与时长。不保存图片、Secret、真实联系方式或未授权正文，不自动上传。
