# Candidate14 Reference V5 与 Scorer V5

参照把存在性、执行人、当前性、条件、依赖、可执行性、默认选择、确认状态、材料、时间和完成标准分开。字段未适用记 `N/A`，评分结果为 `null`，不能记 0。

任务匹配采用确定性一对一分配。一个预测任务不能同时满足两个 Expected；缺失任务只形成一个任务缺失根因，未对齐字段不做级联扣分。别名必须按字段预先登记；禁止全局模糊相似度临时洗掉错对象。

当前 wire 的历史/取消概念通过合法 `tense/status/validity/revision` 组合表达，不要求 Schema 中不存在的枚举。正向 oracle 和错误对象、条件反转、完成标准增强、悬空引用、一对多匹配等负向变异均须通过测试。

Reference V5 仍是合成 Development 的单作者工程参照，不是独立人工真值。旧 v4.1、旧 Expected 和 D6 分数保持不变。
