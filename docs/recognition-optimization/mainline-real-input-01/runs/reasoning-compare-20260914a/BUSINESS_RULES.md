# Flash none / low 同期比较业务裁决口径（发送前固定）

- 比较单位是20份完整通知，不把40次请求称为40份材料。
- 两臂固定 `deepseek-flash`、candidate03、正文、scope、参考时刻、时区、Schema、解析与评分；唯一实验变量是 `reasoning.effort` 的 `none` / `low`。
- B臂请求仍携带 `temperature=0` 以保持兼容形状，但官方说明思考模式忽略该参数，因此不声称两臂都受相同 temperature 控制。
- 改变“做什么、何时做、需要什么、什么条件下执行、哪条要求作废/生效”的差异计为实质错误。
- 多余任务、漏任务、材料漏项/多造/错归属、条件误判、无据依赖、取消/替代错误、假日期及错误时间归属分别计数。
- 等价措辞、等价来源引用与等价粒度单列，不自动计为重大纠正。
- 只解析最终 `message/output_text`；`reasoning` 输出项单独留在不可变原始回执中，不得成为任务事实或来源依据。
- 能解析或能写入不等于事实正确；程序写入的错误任务不得算正确保存。
- 模型原答、解析结果、工程回放、真实页面确认分别报告，不互相替代。
- HTTP或解析失败保留在分母；不补调用、不按结果修改配置或口径。
- W11、W12、X05对应的新单元用于重点追踪；其余全部通知用于防止选择性报告。
- low只有在无需实质纠正数量增加、目标错误减少，且时间/条件/取消/修订/解析可用性无实质退化时，才结合等待与费用判断是否采用。
- 这是已见材料开发回归，不是盲测、真人研究或商业准确率证明。
