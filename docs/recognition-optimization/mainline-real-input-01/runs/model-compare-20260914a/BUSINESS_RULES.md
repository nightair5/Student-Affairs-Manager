# 同模型配置变量比较的业务裁决口径（发送前固定）

- 比较单位是20份完整通知，不把40次请求称为40份材料。
- 两臂只允许模型名不同；candidate03、wire、正文、scope、参考时刻、时区、参数和评分依赖必须相同。
- 改变“做什么、何时做、需要什么、什么条件下执行、哪条要求作废/生效”的差异计为实质错误。
- 多余任务、漏任务、材料漏项/多造/错归属、条件误判、无据依赖、取消/替代错误、假日期及错误时间归属分别计数。
- 等价措辞、等价来源引用、字段间等价粒度差异单列，不自动计为重大纠正。
- 能解析或能写入不等于事实正确；程序写入的错误任务不得算正确保存。
- 模型原答、解析结果、工程回放、真实页面确认分别报告，不互相替代。
- HTTP或解析失败保留在分母；不补调用、不按结果修改口径。
- U11、U12用于重点追踪；U08及其他正常案例用于检查取消、时间、条件和独立任务退化。
- B臂只有在无需实质纠正数量增加、目标错误减少，且时间/条件/取消/修订/解析可用性无实质退化时，才可进入6632隔离试用。
- 这是已见材料开发回归，不是盲测、真人研究或商业准确率证明。
