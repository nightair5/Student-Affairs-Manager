# 已结算回答接入的定向复核

范围：runtime 的 paired04 回放、SemanticRepository 私有内存组装后一次 CAS、启动器记录绑定及浏览器显式入口。由主执行者复核，不称独立盲审。

- 启动器校验原账本链、唯一 grant、输入/请求/候选/响应及结算身份；返回对象不含参考事实、评分或凭据。
- runtime 重建候选请求和来源索引，验证实际文本、版本及响应摘要。摘要是内容一致性校验，不是服务商签名。
- 来源、Run、Draft 先在私有内存构造；实际库只接收终态 needs_review。recorded 标识令派发入口独立拒绝。导入没有确认权限。
- 新旧任务、旧来源及原答按 ID 全结构比较；新增正式任务、旧记录改变或事务冲突均拒绝。没有跨库、清库、全局仓储变更。
- 同通知同臂重复导入不增项，另一臂在原来源已存在时拒绝，避免双份确认。
- 定向测试覆盖正常导入、身份篡改、重复、不可派发、原子失败和正常复原；首次失败为新测试误用不存在的 decisions 字段，第二次为按数组位置比较 prepend 来源，均保留测试日志，未修改旧断言。

结论：本次写入边界未见阻断问题；不是模型质量结论。最终检查需绑定最终源码，浏览器操作与独立读库另列。
