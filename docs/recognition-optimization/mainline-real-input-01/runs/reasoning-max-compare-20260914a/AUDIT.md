# Flash Max 能力验证审计

## 一句话结论

`reasoning.effort=max` 不适合替换当前 `none + candidate03` 基线。首批 8 份同材料正式比较中，Max 虽把 W11 的任务/材料/条件三个错误全部修正，但在 X05、W10 等正常通知新增了多余任务、材料错归属和假时间。无需实质纠正的来源从 `6/8` 降为 `5/8`，实质错误从 `5` 增至 `9`。Max 的中位等待约为 none 的 `11.57` 倍，费用上界约为 `7.88` 倍，因此按预先规则停止剩余 12 份，不采用 Max。

## 固定比较设计

- 两臂均为 `deepseek-flash`、candidate03、同一 wire、正文、来源索引、参考时刻和时区。
- A 臂 `reasoning.effort=none`；B 臂 `reasoning.effort=max`。
- 两臂都使用 `max_output_tokens=32768`、`stream=false`、180 秒超时，无 verifier、Repair 或传输 retry。
- A 的 `temperature=0` 有效；B 兼容提交该字段，但思考模式下服务商忽略它。
- 首批 8 份在取得新回答前固定为 W11、W12、W02、X05、W10、X01、W07、W01；包括复杂关系、模糊时间、明确准备动作及两个正常对照。
- 所有 16 次请求都是正式比较；没有额外试连接、重试或补调用。

官方文档核验：[`deepseek-flash` 映射及价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[Responses 参数与输出额度](https://api-docs.deepseek.com/api/create-response/)、[思考模式与 temperature 行为](https://api-docs.deepseek.com/guides/thinking_mode/)。服务商没有为本次响应提供不可变模型版本，记录的是请求名、实际返回标识和调用日期。

## Y01-B 与接入边界

上一轮 Y01-B 的原始响应、请求身份、模型标识和 usage 可核验，因此本轮按公开价格追加了 `0.075140` 元的用量核销事件；原响应仍是 `incomplete/max_output_tokens`，继续不可评分、不可回放、不可确认。没有把失败改成成功，也没有改写旧停机事件或 A01 未知预留。

Max 接入只增加显式新策略。推理项与最终 message 分开，只有完整最终答案进入建议；总 output 用量只计费一次，没有再次叠加 reasoning tokens。历史 candidate03、modelWire、原回答、Expected、评分器和正式仓储均未修改。

16 个已完成回答最初被冻结旧 envelope 解析器的 8192 总输出上限拒绝评分。修复仅在网关已验证后提取最终 message，并把可见答案投影到旧评分器；服务商 raw、真实 usage、账本和请求绑定不变。原失败 RESULT 保留，离线派生评分另存为 `FIRST8_DERIVED.json`。

## 产品与真实保存

本轮官方浏览器只连接一次，约 22.666 秒后返回 `nodeRepl.fetch request failed`，没有得到可操作标签。因此本轮两条旅程、刷新、独立 new repository 读回和两个实际下载均为 `NOT_RUN`，没有新增正式任务。

既有 6632 历史证据仍保留：candidate03 的工程回放曾证明 20 条事实正确任务可保存于 16 份来源；先前 Q01/Q07 页面旅程和 U11 双路径下载也仍有效。但这些都不冒充本轮 Max 的真实浏览器转化或新保存结果。Max 未采用，所以 6632 路由和公开产物无需修改。

## 工程结论

- 完整预算/网关回归 `122/122` 通过；Max 配置、32768 上限、180 秒超时、推理隔离、可信 usage 核销和不完整答案不可保存的定向测试通过。
- lint、TypeScript、Node 语法和禁用根 `.env` 的临时 Vite 构建通过；保留 4 个旧 lint 警告和旧 chunk 警告。

- 旧 RCO-5-007 的 `package-lock.json` 冻结 SHA 不匹配继续单列；本轮锁文件无 diff，旧断言未删除或弱化。

工程结论为 `PASS_WITH_RETAINED_HISTORICAL_FREEZE_FAILURE`；模型结论为 `STOP_AFTER_FIRST8_AND_KEEP_NONE`；浏览器结论为 `NOT_RUN`。三者不能互相替代。

## 产品决定

继续采用 `deepseek-flash + candidate03 + reasoning.effort=none` 作为隔离实验可靠基线。Max 只在 W11 这类复合关系通知上显示局部收益，但整体错误、等待和费用均退化；本轮不新增自动复杂度路由。下一次若继续提高首次识别，应针对“否定/限制说明被造为任务、任务对象被造为材料”做单变量改进，而不是继续提高思考强度。
