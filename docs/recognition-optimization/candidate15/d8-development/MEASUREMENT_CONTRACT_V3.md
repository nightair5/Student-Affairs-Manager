# D8 计时与正确处置口径 3.0

工程回放只记录仪器链路；不产生真人正确率。任何 `HUMAN_TRIAL` 均需另有权威注册与真实独立语义判定，本入口硬性拒绝登记。

开始试次、冻结首次回答、进入可交互建议后，分别记录阅读、编辑、空闲、系统等待、页面隐藏与总墙钟时间。编辑由真实字段输入开启，成功保存或明确结束关闭；连续两事件间最多 5 秒算活跃编辑，剩余记空闲。隐藏优先于系统等待，系统等待优先于空闲，互斥分桶；未闭合区间不报确定耗时。尚未能判断的区间进 `unclassifiedMs`，不填 0。自动化时钟只验证链路，不能冒充人的主动修改时间。

每个字段的一段编辑有 `editId`；在同一次保存前切换字段会先结束上一段并新建 ID。`commit_succeeded.includedEditIds` 将这些 ID 显式映射到保存 `commitId`，再由独立读回验证。缺映射则修正数、低修改正确处置率为 `null`，不是 0/通过；未知编辑类别保守计入实质修改。修改后撤销、失败、超时与放弃保留已经发生的编辑时间及次数；最终净差异只用于交叉检查，不抹掉操作成本。来源首次输出哈希在每条事件中保持不变。

四项指标的真人分母均为**全部已开始且合法登记的试次**。无效注册不进入合法分母，另报 `invalidHumanRegistrations`；合法登记后事件身份坏掉仍留在分母并计为缺失。`firstWholeCorrect` 和最终处置正确性需要独立语义判断；缺判断、身份问题、仪器缺口分别计数。主动修改时间同时报告有效 n 和缺失 n，失败/放弃/超时的负担也进入统计。低修改主口径为零实质语义纠正，并不缩小分母。

已实现：老 2.4 只读诊断保留；3.0 工程反例覆盖阅读、双字段批量映射、映射缺失、超时负担与隐藏/等待/空闲；D8 隔离页面的标题/日期输入、事实编辑与确认接入事件记录。当前真实 UI 尚未对所有事实编辑分类和阅读/隐藏/等待状态给出完整仪器事件；未知类别保守算一次实质编辑，但语义正确性仍要独立判断；刷新跨段耗时为缺失。未开展真人试用，四项真人指标仍为 `NOT_OBSERVABLE`。
