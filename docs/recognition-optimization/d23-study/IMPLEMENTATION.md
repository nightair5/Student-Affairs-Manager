## 角色与保存安全

运行配置的角色不可由页面切换。当前 `ENGINEERING_REPLAY` 的 4 个全新库不能转成真人库；复制注册表、改角色、错来源/刺激、错参与者、旧裁决或未授权开始均被阻断。未来 `HUMAN_EXPLORATORY` 只能在另行明确授权之后由本机服务加载真实范围引用；配置必须匹配冻结计划、负责人及 4 人 16 条范围。不是账号认证：本机负责人需安排参与者只操作自己的身份，私人映射及同意原件不进入 Git。本次未创建真人授权配置。

页面只允许当前锁定通知的 GET 录制记录；旧 Storage、非白名单 IndexedDB、模型 API、XHR、Socket、Beacon 和外部请求关闭。服务绑定 `127.0.0.1`，不读取 `.env` 或 Secret。跨试次保护同时覆盖页面测量、检查点和正式存储，不只靠禁用按钮。初始化只允许空 Workspace；不存在的历史来源不能随意插入。

保存安全继续使用 D22：正式写失败不产生半份事实；已提交但读回失败保留 commit，只重新读回。原始回答、程序兼容转换及用户输入分别保留。空白手动封套的 0 usage 是解析兼容占位，不是供应商观测值，不进入任何 API 成本或模型质量报告。

## 新测量口径

`d23-semantic-measurement-1`：空闲界限 5 秒、low-edit-v2 至多 2 个语义字段及 30 秒主动编辑、结构修改不豁免、完成窗 10 分钟；正式试次前由真实负责人核准。历史 measurement 3.2/low-edit-v2 实现与结果原样并列。

manual 的初始录入与 assisted 的纠错分开；manual 首次建议和低修改收益为 NOT_APPLICABLE。辅助首次正确只评价实际打开的固定录制；开始但退出且没打开建议不算刺激暴露。相同录制多次展示不充当多个独立模型样本。完整正确须负责人逐事实裁决、整份终态及独立读回共同成立；有争议则未知。无真实试次，本次四项真人指标全部 NOT_OBSERVABLE。时间只反映 UI 活动，不声称测量认知努力。

## 本机操作

```powershell
node scripts/serve-d23-study.mjs 6725 final01
node scripts/verify-d23-study.mjs .data/d23/final01
```

唯一推荐工程入口 `http://127.0.0.1:6725/?automation=1`；本机服务存在时可用。`final01-p1`—`p4` 是工程模拟库，原 D22 6718 及其库不动。不要把工程库清空、复制或改名用于真人。

只有收到真实范围授权、负责人接受及参与者同意后，使用新的实例和 `human` 库；负责人先核准全部最小义务、完成窗与测量，再登记真实引用。一般参与者入口不显示负责人裁决；本机负责人入口 `?owner=1` 提供登记、冻结及逐试次裁决。该页面分工不是安全账户隔离，未来远程/多用户发布须另做认证、权限及部署验证。

工程证据、实际缺项与测试分组见同目录结果、浏览器和验证文件。本轮不默认生成新 24 身份；只有真实探索显示需要新模型假设时才申请独立批次。
