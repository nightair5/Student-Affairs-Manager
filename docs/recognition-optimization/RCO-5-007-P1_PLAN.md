## 唯一变量

唯一变量是新增的 `task-formation-policy-2.1.0-p1`。B2 数据、Expected、scope index、评分器和旧 `task-formation-policy-2.0.0` 均保持原字节。

P1 按四层顺序处理：

1. **当前义务层**：根据有效、未完成、肯定、必做命题计算 `requiresAction`，不读取 `selected`。
2. **任务边界与对象层**：只有动作对象与目标一致时才允许复合；合法的逐字对象引用优先原样保留。
3. **效果与风险层**：结合动作、对象和同一 scope 上下文分类本机变更、外部传输、外部交互和实体动作；未知或矛盾时失败关闭。
4. **默认选择层**：只对证据明确、当前有效、风险允许的建议默认勾选；外发、支付、报名、联系、签名、参加和不确定项保持未勾选。
