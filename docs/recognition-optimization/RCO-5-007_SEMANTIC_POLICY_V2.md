# RCO-5-007 语义与任务形成政策 v2

## 权威边界

模型输出只是“原文哪里可能包含什么”的候选索引。以下字段只允许本机构造：最终任务边界、语义标签、`requiresAction`、`selected`、证据位置、说明归属与安全结论。模型提供的同名字段必须被丢弃，不能作为默认值。

## 任务边界

- 同一 scope 内连续动作，如果服务于同一对象链且没有独立的截止时间、接收方或外部副作用，形成一个任务；首个动作作为主动作，其他动作进入步骤。
- 不同 scope 默认形成不同任务。只有明确的回指说明可以附着，不允许跨 scope 猜测合并。
- 材料名、地点、联系方式、背景、标题、格式说明不能独立成为任务。

## 状态与时态

- 面向收件人的命令表示尚待执行，时态为 `future`。
- `已/已经/完成/办结` 表示 `past + completed`。
- 否定和禁止词表示当前不可执行：`negative + cancelled`。其中“暂勿”保留 `temporary_hold` 原因标签，但仍不得默认执行。
- 含 `若/如果/如/当…时` 的命令，除非同一来源明确说明条件已触发，否则为 `hypothetical + uncertain + unknown`。
- `旧通知/原安排` 被后续 `取消/作废/改为/最新更正` 指向时，旧项为 `superseded + cancelled`，新项按正文重新判定。

## 说明归属

- “该信息/该安排/上述任务/两项/本次”等回指，只能指向前方最近且类型相容的命题。
- 共享材料说明附着到明确提到的全部任务，不再输出独立任务。
- “仅供参考/不是本次要求/不要求/不强制/尚未发布”是说明或限制，不产生正向任务。
- 引用、界面示例和问题征询保持 observation，不转成默认任务。

## 本机安全决策

只有同时满足下列全部条件的项目才可默认勾选为“待确认建议”：

1. 原文明示，且动作和对象能回到不可变 scope；
2. 面向收件人的当前有效命令；
3. 正向、待办、必需；
4. 非条件、非引用、非历史、非修订旧项；
5. 不涉及提交、上传、发送、联系、报名、付款等外部副作用；
6. 通过本机契约与字段—证据支持校验。

任何缺项都必须 `selected=false`；不确定时保留给用户核对，不能靠第二个同模型调用放行。

## 与 B1 Expected 的关系

B1 只用于已见问题诊断，不用于制定规则。若既有 Expected 对“暂勿”等状态的标法与本政策冲突，报告必须单列为政策差异，不得为提高分数修改政策或 Expected。
