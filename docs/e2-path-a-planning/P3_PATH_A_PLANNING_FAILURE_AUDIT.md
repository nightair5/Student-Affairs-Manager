## P4 输入结论

P4 只允许处理不新增事实的确定性结构规范化。事实缺失、动作谓词错误、时间值错误、条件/歧义遗漏、Event/Task 语义混淆不能由 PlanningNormalizer 猜测修复；合理等价结构与 strict scorer 错配也不能通过修改 expected 刷分。
