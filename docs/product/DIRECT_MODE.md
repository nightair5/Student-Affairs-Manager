# 直达口径（负责人2026-10-25决定）

默认流程由点击整理授权自动添加，可编辑、删除、按批次撤销。来源与AI回答仍保留在详情，不更改历史原答、参照或成绩。

2026-11-15 本机作用域规则：条件前件与自己的谓语一起解析；独立附加提交保留适用条件、材料、渠道与时间，不把重叠条件变成二选一或借用主步骤截止。多目标通知中，条件必需/真正可选材料按明确章节与唯一主事项保存；不把单数“该材料”随意分配给多个文档。时间状语与动作前渠道分开验证，例如“周五前向平台上传”不能把日期放进渠道。明确的“同日/当日/当天”可越过同一章节的说明句及空行，需唯一活动日期；新章节、多候选、截止、改期仍阻止继承，已知钟点与跨午夜端点保留。说明义务不成立的比较句与组织方条件流程不变成用户个人任务；独立肯定指令仍保留。新增实体全部走现有直达事务，条件、关系、材料、个人计划和独立完成状态随 Workspace v8 保存。本机改进不改 AI 生成默认，单人工程回归不当作 Flash 准确率。

2026-11-14 本机作用域补充：跨午夜起止作为同一个时间事实；“同日”只能在单一明确的局部日期依据内继承日期，不继承前场的钟点、地点或取消状态。交付形式对照中的省略对象必须有唯一前文材料和明确的仍需提交语句，取消某形式不能删除另一形式义务。组织方审核日期保留在后续办理说明；明确邀请用户参加及条件入选后的活动分别保留。普通已完成待办可在详情恢复未完成，复用事务、修订及用户编辑保护，不改变原截止与材料。

负责人2026-10-28要求：相同通知可以由用户再次主动整理，新增独立批次并保留先前事项；同一次提交的连点、失败重试和读回不得创建额外副本。

纯信息的“查看”待办是产品规则产生的阅读动作，不宣称原文要求学生执行；纯取消通知也只建立查看更新，取消的原行动不复活。信息日期使用planned_start，不改为截止。

2026-11-01 产品规则澄清：真实活动可单独形成日程，不为同一活动额外创建阅读待办；原文有行动但未能完整整理时明确标示部分内容待补充，不能将其伪装成纯信息。用户后来编辑过的批次，产品撤销入口保留原内容并提示逐项处理。

2026-11-04 展示规则：同一来源中有明确、线性前置关系的待办，首页可以合在一个事项内按步骤展示；每步仍是独立保存的待办，保留各自的时间、渠道、材料与完成状态。无明确关系、存在分支或互斥选择的事项不按名称猜测合并。

2026-11-05 展示规则：个人已完成的日程不占据首页时间轴，可在日历的“已完成的日程”中恢复；日期明确的日程在今天及接下来两天以红色和文字提示，不改变保存的时间。

2026-11-05 活动附带事项：与具体活动明确相关的可选入群、提前入场等提示，保留在该活动的参加须知中；有独立截止、报名、提交、材料或前置关系的行动仍保留为待办。关联或依据不清时不猜测合并，也不自动改写已保存事项。

2026-11-06 语义保真规则：重复时间引用结合所属事项的原文范围定位；换行和日期装饰不能改变截止角色。日期区间和每日开放时段分别理解，窗口终点取最后一天的关闭时刻；仍保留完整开放说明。取消只作用于对应事项或被替代的旧场次。明确任选的 2—6 种办理方式保留各自截止、渠道和材料，合为一个可选择事项；“不可任选、全部必交”不建立选择关系。完成一个选择分支满足该选择目标，不篡改未选分支的原文事实。

2026-11-07 展示规则：报名、扫码、材料提交与活动有明确来源关系时，在主活动的“需要准备”中集中展示并用黄色提示；各行动仍独立保存时间、材料、条件和完成状态。任务属于同一明确交付目标时可分组，同日或标题相似本身不构成关联。不同活动的日程、地点和状态保持独立。已保存内容不自动改写；用户可主动关联或取消关联同一来源中的已有待办。

2026-11-11 候选组织规则：同一明确办理目标可包含并行、先后、条件或任选行动；是否归属于同一事项与是否存在依赖分开判断。时间、材料、渠道和完成状态分别保存。同日、同邮箱、同一来源或标题相似不能单独证明同一目标；不同活动保持独立。旧记录只在用户主动选择后调整展示关系，不自动改写事实。新识别契约 3.12 仍是待真实对照的候选，线上默认未改变。

2026-11-11 候选保真规则：学期周次、页数等数量范围和周期受理规则不得变成一次性日历日期；可独立确定的日期仍保留。原答已抽取且有依据、但未关联到行动的材料先保存在该来源批次中，默认显示条件及“适用事项待关联”，不自动认定为可选或全部必交。来源简介明确界定共同目标时，成员标题不必重复主题；归组仍不能跨越另一独立通知。超容量本机结果保留原文与部分完成说明，失败兜底的日期基准固定为来源版本时间。

条件未知的真实义务有“如符合条件/待确认”标签，时间不明留空，不能成为确定必做或自动排期。负责人2026-10-25第25轮决定：标签不再决定隐藏或等待；首页分为刚添加、今天和接下来、待安排，只有未完成前置或用户主动稍后才进入稍后再做。旧核心可用与v5.1/v6照常保留为识别诊断，不能把新增阅读待办算成模型识别收益。
