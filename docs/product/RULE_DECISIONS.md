# 需负责人确认的产品规则

以下采用保守且可撤回的当前表示，不等同于负责人已作裁决。

| 问题与例子 | 两种合理选项 | 当前建议 |
|---|---|---|
| “到北门集合” | 单独行动；固定活动的地点/参与要求 | 已有同一活动时保留为活动属性；只有独立准备或交付义务才增加待办 |
| “随后答疑” | 同一活动环节；独立事件 | 不同名称且有独立起止时分事件；只给环节说明时保留属性，不凭空造时间 |
| “见附件/同上”但未粘贴附件或上条 | 推测常见要求；保留明确缺口 | 保留正文义务，提示附件未处理；不猜材料、地点、渠道、截止 |
| 已录取者参加，个人结果未知 | 保存条件事件；不保存事件 | 保存条件与未定资格，但不产生确定个人占用；可确认无关报名义务 |

评测参照在看输出前固定。未决的额外行动/事件保持争议和分母，不能用本表事后填满分。
