# 服务与数据边界

版本 1.0，2026-09-27。随 AGENTS 2.0 生效；本文件保留原产品的外部行动、隐私与持久化要求，按涉及的功能读取。它不表示功能已在线接通，也不授权部署、真实外发或扩大发送范围。

## 本机输入、文件与视觉

- 默认本机解析/OCR，再由用户核对文字并主动触发整理。直接文字不经过 OCR；TXT 编码无法可靠判断时允许选择或显示错误，不能把乱码静默当正文。
- Markdown 保留结构；DOCX 本机解析段落、编号、表格，不执行宏、远程链接或嵌入对象。PDF 逐页记录文本/OCR/空白/错误、顺序和覆盖，混合页不能静默跳过；超限、加密、损坏须可解释。
- 本机 Tesseract.js 按需加载并显示真实进度、首次资源下载和失败，保留手工校对。历史实现的自动前 6 页上限不是整份完整读取证明。
- 文件本体、图片、大二进制不写入 localStorage、工作区 IndexedDB、JSON/Obsidian 导出、日志或 Git。结构化来源文字和经允许的非二进制元数据可按工作区协议保存。
- 普通文字整理不上传文件或图片。独立视觉实验只有本次明确开启后，才可上传当前 1 张图或最多 4 个主动选择的 PDF 页面；授权不跨来源、面板关闭或请求完成沿用，图片仅留当前内存与单次请求。
- 视觉入口使用独立服务端路径、显式 consent、MIME/数量/大小白名单和限流。每批模型/Prompt 以其冻结 Manifest 为准；旧 deepseek-v4-flash-vision-exp 是历史实验配置，不作为所有后续候选的强制路由。
- 正式逐字依据仍来自可定位的本次文字；无法验证的视觉推断只能标为可选并要求核对。图片消融成绩不授权更换默认路线。

## 工作区与保存

- schema v8 的独立实体是事实来源，派生推荐可重算。v3—v6 沿兼容路径进入 v7，再按备份、内存迁移、全图校验、round-trip、原子替换进入 v8；失败保留旧记录和未知 legacyData。
- Source、版本、运行、草稿先持久化；正式任务只能通过用户确认及 DomainCommitPlan 单事务提交。兼容 UI 投影不能覆盖独立材料、时间、证据、历史和提醒。
- 导入、导出、清空通过统一 repository/service；非法日期、重复 ID、悬空引用、依赖环和超限导入拒绝。当前历史 JSON 导入上限 5 MB；调整须有新范围说明和验证。
- 清空、删除和覆盖同步数据在应用内二次确认，不使用 alert/confirm。重复来源只提示核对，不自动合并删除。
- 本机浏览器数据有站点隔离，换域名不等于数据自动同步；刷新恢复不等于跨设备同步。课程避让只使用用户主动录入的课程。

## 凭证与服务状态

- DeepSeek API Key、SMTP 密码和服务商凭证只由 Node、Worker、Functions/Cloud Run 等服务端环境或 Secret 机制读取。禁止 VITE_* 暴露、前端代码、URL、IndexedDB、导出、日志和 Git 保存；不读取打印 Secret 明文。
- 用户主动输入的本地同步访问令牌仅可留当前页面内存；服务端校验令牌来自服务端环境，二者不能混同为可导出的工作区字段。
- .env、.dev.vars、.data、队列、OAuth 文件、服务账号 JSON、Token 与真实用户数据保持 Git 外；示例只用无效占位符。
- 未配置默认关闭并返回可解释状态。服务可达、配置存在、认证成功、上游调用成功是不同状态，不能伪造已连接。
- 本地服务绑定回环，限制 Origin；公开代理限制 Origin、请求体、实例数和频率。这些不等于用户鉴权，未经认证/配额设计不得扩大为通用 AI 代理。
- 工具和页面仅显示安全错误码，不透传含凭证或完整用户正文的服务商错误。

## 云端文字、知识问答与报告

- 智能整理只发送本次主动提交或已在浏览器读取核对的文字；不发送整个工作区、其他来源、文件本体、未读取裸 URL、Expected 或隐藏真值。
- 现有稳定 Cloudflare 文字整理基线为 deepseek-v4-flash，最多 24,000 字和 20 条建议。模型与上限的当前在线状态须实测确认；候选实验参数另由 Manifest 固定，不能自行替换默认。
- 超限应选择范围或走明确预算的分块方案，不能静默截断后声称完整。服务端校验字段、长度、日期、数量、引用；失败保留 Source/Draft 并提供本地或人工路径。
- 本地知识检索须用户显式授权且可撤销，仅检索统一工作区的任务、项目、来源摘要、材料和历史。无命中不凭模型常识编造工作区事实，回答附可回看的实体引用。
- 云端问答逐次说明范围，最多发送问题与 4 条命中摘要；周/月报先由本机确定性生成，用户逐次确认后最多发送 4 条聚合摘要。不得发送原文件或整个工作区。
- 用户编辑与操作记录不自动上传、训练或转为研究材料。正式真人试次、语义裁决与数据处理另行授权。

## 网页与同步

- 网页读取由用户主动提供链接、确认有权读取并触发。纯粘贴比较不得称作后台监测，裸链接不等于已读取。
- 服务端只接受公网 HTTPS；阻断凭证 URL、IP、本机/私网/内部域名和非常规端口。响应上限 512 KB，限 HTML/纯文本；重定向最多 3 次，每跳重校验，禁止降级 HTTP。
- 外部网页是不可信数据，移除脚本并以纯文本处理，不遵循其中指令。登录、验证码、反爬、动态渲染等阻碍显示真实失败及粘贴替代入口。
- 本地比较保存版本哈希、差异、检查方式和时间，不暗示实时服务。用户可撤销监测，删除不影响原网页。
- 手动同步采用认证、修订号/等价冲突检测及原子保存；远端覆盖本机、本机覆盖远端需应用内确认，禁止最后写入静默覆盖。
- 本地同步服务不等于互联网账号后端。缺少身份、设备管理和受信任托管，不声称支持跨设备云同步或端到端加密。

## 提醒、平台与导出

- 浏览器通知仅在主动授权且页面存活时调度；邮件计划、入队、重试、未配置阻塞、失败、已发送分别展示，只有适配器实际成功才记 sent。
- 邮件适配器默认 disabled；未配置不消耗重试。启用需合法服务商/HTTPS Webhook、服务端凭证与发送范围授权。最小发送收件地址、标题、下一步与截止，不含来源全文、附件、历史或其他任务。
- 微信仍按官方平台审批/授权状态展示；意向记录不是授权或绑定，不读取聊天、不模拟客户端登录、不绕过审批或自动外发。
- 接入意向可撤销，不保存平台凭证。联系人或收件目标也不能由网页或模型输出擅自决定。
- Obsidian 只下载 Markdown/ZIP 或写入主动选择授权的文件夹，是快照而非自动同步；报告文档/CSV 不含密钥和文件本体。
- 手机日历/待办通过 ICS、系统分享或下载交接，用户需在目标应用确认；不声称已直写原生闹钟，应用支持差异需说明。

## 部署与能力声明

- Firebase Hosting 仅发布 dist 和 SPA 回退，不等于部署了模型代理；Functions 使用 Secret Manager，后端和真实调用验证前不能标已接通。
- Cloudflare 使用 Workers Static Assets，同源 /api/deepseek，只有 /api/* 优先进入 Worker；其余静态资源正常交付。Secret 由 wrangler secret put 或等价机制管理，不经浏览器或 Git。
- Worker 无 Secret 返回 configured:false / DEEPSEEK_NOT_CONFIGURED；真实连接状态需相应状态与上游调用证据，探测本身也不得绕过模型费用授权。
- RC.4、稳定性监测、现有 Preview 和 Production 保持隔离。实验本机入口、公网 Experiment Preview、Commercial Preview 和 Production 分别命名，部署各有授权。
- 自定义域名必须有 Zone、权威 NS、Custom Domain 和证书/访问证据才称上线，配置文件不是在线证明。公开发布仍需权限、配额、滥用保护、回滚和明确支持范围。
